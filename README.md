# Our Journey Together

A romantic, interactive 3D digital flip-book made with love — soft pastels, page turns, and a few playful surprises.

## Open locally

**Option A — open the file**

1. Open `index.html` in your browser (double-click or drag it into a window).
2. The three files stay together: `index.html` links `style.css` and `script.js`.

**Option B — simple static server**

```bash
python3 -m http.server 3847 --bind 127.0.0.1
```

Then visit [http://127.0.0.1:3847](http://127.0.0.1:3847).

## Files

- `index.html` — structure & copy
- `style.css` — pastel look & CSS 3D page flips
- `script.js` — navigation, slideshow, runaway buttons, celebration

No build step. Pure HTML, CSS, and JavaScript.
